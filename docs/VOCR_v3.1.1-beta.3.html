Changelog

  • On macOS Golden Gate 27, the first scan may have to compile text recognition models, which can take up to a minute. VOCR announces when this happens.
  • When text recognition fails, VOCR reads the error instead of saying "Nothing found."
  • With Log on, each scan logs extra details for troubleshooting: timing, system info, the model cache and macOS's text recognition messages.
  • Choosing a language now offers to relaunch VOCR, since the change takes effect only after a relaunch.
  • The Language menu checks System Default when no language is chosen.
  • Launch on Login no longer turns itself back on or shows the wrong state.
  • Fixed a crash when toggling items in the Settings menu.
  • Updated Spanish translation (#54, thanks @CarlosEstebanM and @Kiko0923).
  • Updated Italian translation (#53, thanks @phonegiovanni-svg).
