Reasoning Effort for Presets

Each preset now has a Reasoning Effort setting in the preset editor, below the model.

  • Choose a value from the Reasoning Effort popup (none, minimal, low, medium, high, xhigh, max), or type any value your model supports in the text field next to it.
  • Leave the field empty to use the model's default. VOCR then doesn't send any reasoning effort to the model.
  • The setting applies to both Ask and Computer Use.
  • Existing presets keep using the model's default until you set a value.
  • Computer Use used to always send reasoning effort "none". It now follows the preset, so set the preset to "none" if you want the old behavior.
